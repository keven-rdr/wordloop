# Login (BFF) na API

> Arquivo: `docs/features/2026-10-13-login-bff.md` · Issue: #__ · Branch: `feat/login-bff` · Estado: BUILD

## Contexto
Sprint 1, item I-01. A API é o cliente OIDC (code + PKCE) e entrega ao navegador só um cookie `httpOnly`; o token nunca chega ao JavaScript. Esta fatia é só a **API**; a tela de entrar/sair vem na PR seguinte.

## Definições confirmadas
- **Escopo:** `GET /auth/login`, `GET /auth/callback`, `POST /auth/logout`, `GET /me`. Tela web fica para a próxima PR.
- **IdP:** padrão OIDC, então a API não conhece o provedor. **Dev:** Keycloak do Compose (`wordloop-dev`). **tst:** IdP OIDC externo gratuito (a VM de 1 GB não comporta o Keycloak). Nada de login simulado.
- **Sessão no servidor:** cookie `wl_session` (`httpOnly`, `SameSite=Lax`, `Secure` quando a URL pública é https); no banco só o **hash SHA-256** do id e o refresh token **cifrado** (AES-GCM, `SESSION_KEY`).
- **Estado do login** (state, nonce, verifier PKCE, destino) em cookie curto `wl_oidc`, também cifrado e `httpOnly`.
- **Perfil:** `app_user` criado no primeiro login (JIT). Como o `sub` de um IdP externo pode não ser UUID, o `id` é gerado pelo app e a identidade é o par `(idp_issuer, idp_subject)` (migração aditiva). E-mail e senha **não** são copiados para o nosso banco.
- **CSRF:** cookie `SameSite=Lax` + `POST /auth/logout` exige o cabeçalho `X-Requested-With: XMLHttpRequest`. `return_to` só aceita caminho relativo (`/...`), nunca URL externa.
- **Sem IdP configurado** (`OIDC_ISSUER` vazio): a API sobe normalmente; `/auth/*` responde **503** e `/me` responde 401. Assim tst não cai antes de existir o IdP.

## Decisões
- Módulo `internal/identity/{domain,app,adapters}`; a interface do consumidor fica em `app`. `api.Server` só delega ao handler do módulo.
- `sqlc` entra aqui (primeiras consultas: `upsert app_user`, sessões).
- Erros sem corpo por enquanto (401/503): o catálogo de Problem Details (`code` + `params`) entra numa PR própria.
- Teste de integração com **Keycloak real** (Testcontainers) reaproveitando o realm de `deploy/dev`.
